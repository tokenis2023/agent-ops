# fsops v0.4.0

面向 AI Agent 的 Windows 文件操作层，MCP + CLI 双形态。本版不加新工具，把 0.3.0 之后暴露的契约、轮次与后台任务问题一起收掉。

## 契约与自检

- `fs_exec` 的 schema 允许只传 `job`：轮询/终止后台任务不再被 `required: program` 拦在宿主侧。
- `fs_stat detail=server` 返回 `fsops 0.4.0 tools=8`，一条调用确认服务端版本与工具数。
- `fs_edit.files[]` 补 `normalize_eol`；`fs_file.encoding` 补 `utf-8-bom`。
- `fs_read` 的 description 增加模式互斥表（path/paths/reads/focus 四选一）。
- 新增 `fsops schema` 子命令；DSH 冒烟测试逐工具比对参数集合，三处手写 schema 的漂移从此变红灯。
- 文档防漂移测试：扫描源码全部 `E_*` 错误码，断言工具参考覆盖每个码与每个工具章节。

## 减轮次

- `fs_exec check=true`：非零退出按 `E_EXIT code=N` 返回，默认仍是 `ok`。
- `fs_exec job` 支持 `wait_ms`：最多等待 N 毫秒直到任务退出再返回，短命令一次调用拿全结果。
- `fs_edit` 的 `E_AMBIGUOUS` 附前 3 处命中片段，并在同行多处匹配时给出列号与 `^` 指针。
- `fs_edit` 的 loci 在同线路号时追加列号（`1,1:11,1:19`）。
- `fs_read reads[]` 每项支持 `budget` 与 `focus`：大文件单项多要预算，多文件按模式取块一次完成。
- `fs_read reads` 输出首行改为 `ok reads N 项：X 成功，Y 失败`。
- `fs_exec list=true` 列出当前会话的后台任务，丢了 job id 能自救。

## 修复

- `fs_file copy/move` 目标路径统一 POSIX；`move` 报真实字节与文件数。
- `fs_file convert` 到 `utf-8-bom`/`utf-16*` 写入 BOM。
- `fs_exec job` 的增量解码不再切断多字节字符。
- `fsops mcp --jobs 0/1` 升为单工作线程：`background`/`wait_ms` 不再占住读线程。
- CLI 退出码与 MCP `isError` 共用 `E_` 行判定。
- `E_LINE_TOO_LONG` 明确「渲染剩余预算」而非请求值。

## 一行安装

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://github.com/tokenis2023/agent-ops/releases/latest/download/install.ps1 | iex"
```

自动完成：下载最新版 → SHA-256 校验 → 安装到 `%LOCALAPPDATA%\fsops` → 加入用户 PATH → 注册检测到的 Claude Code / Hermes / Codex。

卸载：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://github.com/tokenis2023/agent-ops/releases/latest/download/uninstall.ps1 | iex"
```
