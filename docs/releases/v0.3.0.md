# fsops v0.3.0

面向 AI Agent 的 Windows 文件操作层，MCP + CLI 双形态。本版修掉 0.2.7 后半程暴露的输出与契约问题，并把文档、DSH 插件与 MCP schema 全部对齐。

## 修复

- `fs_file copy/move` 的目标路径统一输出 POSIX（此前是 `C:\...` 反斜杠）。
- `fs_file move` 同盘 rename 报真实字节与文件数（此前恒为 `0B` / `1 个文件`）。
- `fs_file convert` 到 `utf-8-bom` / `utf-16le` / `utf-16be` 时写入 BOM。
- `fs_exec job=<id>` 的增量解码不再切断多字节字符。
- `fs_read reads` 的预算严格按项均分，放不下文件头时返回 `E_BUDGET`。
- CLI 退出码与 MCP `isError` 共用 `E_` 行判定，夹在正文里的错误也会返回 2。

## 契约与文档

- `fs_edit.files[]` 补 `normalize_eol`；`fs_file.encoding` 补 `utf-8-bom`。
- DSH 插件对齐 8 个工具与 `reads` 的 `ranges` / `scan`。
- 工具参考补「文件管理与执行」9 个错误码。
- README / 使用指南 / CONTRIBUTING 对齐 8 工具、`fs_exec` / `fs_file`、Rust 1.88。

## 一行安装

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://github.com/tokenis2023/agent-ops/releases/latest/download/install.ps1 | iex"
```

自动完成：下载最新版 → SHA-256 校验 → 安装到 `%LOCALAPPDATA%\fsops` → 加入用户 PATH → 注册检测到的 Claude Code / Hermes / Codex。

卸载：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://github.com/tokenis2023/agent-ops/releases/latest/download/uninstall.ps1 | iex"
```
