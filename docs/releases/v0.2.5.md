# fsops v0.2.5

面向 AI Agent 的 Windows 文件操作层，MCP + CLI 双形态。本版目标是消掉 agent 写代码时最常见的两种浪费：**为了抄原文而读**，和**改完再读一遍确认**。

## 一行安装

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://github.com/tokenis2023/agent-ops/releases/latest/download/install.ps1 | iex"
```

自动完成：下载最新版 → SHA-256 校验 → 安装到 `%LOCALAPPDATA%\fsops` → 加入用户 PATH → 注册检测到的 Claude Code / Hermes / Codex。

卸载：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://github.com/tokenis2023/agent-ops/releases/latest/download/uninstall.ps1 | iex"
```

## 本版重点

### 读 → 改 → 再读，压成一次调用

典型 agent 流程是：读文件（为了抄准原文）→ 改 → 再读一遍确认。三次调用里，只有一次在真正推进任务。

实测（40 行源文件，改一行）：

| 做法 | 调用次数 | 工具输出 |
|---|---:|---:|
| 读 → 改 → 再读 | 3 | 2,579 字符 |
| `fs_edit diff=true` | 1 | 160 字符 |

**省 94%，且不再需要回读确认**——diff 直接给 `@@ 行号` + `-原文` / `+新文`。

### 正则替换：连第一次读也省掉

`edits` 的每一项可以用 `pattern` + `replacement` 代替 `old` + `new`：

```json
{"pattern": "let limit_(\\d+) = \\d+;", "replacement": "let cap_$1 = 500;"}
```

```text
ok 30 处修改 (+30 -30) @ 2,3,4,5,6,7,8,9 … 共30处  hash=860b6796
@@ 2
-let limit_0 = 100;
+let cap_0 = 500;
```

值各不相同的 30 行配置，一次改完并保留编号。适用于「知道形状、不知道确切内容」的批量修改。

### 护栏

- 可匹配空位置的正则（`^` `$` `a*` `.*`）直接拒绝——它们会命中每一处。
- 不匹配时报「检查转义，或先用 `fs_grep` 确认形状」，不会建议你去 `fs_read`（那恰好违背用正则的初衷）。
- 同样支持 `start`/`end` 限定行范围、`diff=true` 自查、`dry_run` 先看后写。
