# fsops v0.11.4

面向 AI Agent 的 Windows 文件操作层，MCP + CLI 双形态。本版按真实 Agent 对照修常驻成本与三类误导：工具 schema 瘦身 17.1%、接受宿主参数别名、超时不再说成「不存在」、引导报告当前目录。

## 一行安装

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "& ([scriptblock]::Create([Text.Encoding]::UTF8.GetString((New-Object Net.WebClient).DownloadData('https://github.com/tokenis2023/agent-ops/releases/latest/download/install.ps1')).TrimStart([char]0xFEFF)))"
```

卸载：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "& ([scriptblock]::Create([Text.Encoding]::UTF8.GetString((New-Object Net.WebClient).DownloadData('https://github.com/tokenis2023/agent-ops/releases/latest/download/uninstall.ps1')).TrimStart([char]0xFEFF)))"
```

## 本版改动

- 9 个工具 schema 18,476 → 15,319 B（−17.1%）：删掉嵌套项里与顶层重复的描述、与工具描述重复的互斥枚举、`limit` 三种计数口径这类实现细节；参数集合与默认值不变，`fs_read` −24%、`fs_grep` −22%。
- `fs_grep` 接受宿主 `output_mode` 并映射枚举值（`content`→`matches`、`files_with_matches`→`files`）；别名不进 schema，正式参数优先。
- `fs_glob` 超时改为「遍历未完成：不能断定不存在」，给出已访问项数与加大 `time_budget_ms` 的路径。
- `initialize` 引导与 `fs_stat detail=server` 报告当前目录，消除相对路径读错目录的试错。
- 新增真实 Agent 对照 harness 与评测记录：两侧 18/18 成功，fsops 67 次调用 vs 原生 103 次（−35%），未缓存输入仅差 3.2k token。
- 418 单测与 `check.ps1 full` 全绿；无 schema 字段、错误码与写入行为变更。
