# fsops v0.11.1

面向 AI Agent 的 Windows 文件操作层，MCP + CLI 双形态。本版把「默认开发闭环」写进运行时引导、项目规则与文档，不改变工具契约。

## 一行安装

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "& ([scriptblock]::Create([Text.Encoding]::UTF8.GetString((New-Object Net.WebClient).DownloadData('https://github.com/tokenis2023/agent-ops/releases/latest/download/install.ps1')).TrimStart([char]0xFEFF)))"
```

卸载：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "& ([scriptblock]::Create([Text.Encoding]::UTF8.GetString((New-Object Net.WebClient).DownloadData('https://github.com/tokenis2023/agent-ops/releases/latest/download/uninstall.ps1')).TrimStart([char]0xFEFF)))"
```

## 本版改动

- MCP `instructions`、`integrate --rules` 规则块、`AGENTS.md`、README 与使用指南统一为同一条开发路径：陌生仓库先 `fs_inspect` → 按符号与引用了解结构用 `fs_glob map=true` → `fs_grep` 初筛/定位 → `fs_read` 精准读取 → `fs_edit` 批量修改 → 按需 `diff=true` 自查 → 相关测试 → 项目最终检查。
- 多步骤任务要求跟踪进度；长构建/测试走 `fs_exec` 后台任务；完成前核对改动范围、测试结果与剩余风险。
- 明确 repo map 属于 `fs_glob`，避免把 `fs_inspect` 误读为自带结构导航。

**测试**

- 新增两条引导回归测试，并把 `fs_glob` 纳入关键词；404 单测与 `check.ps1 commit` 全绿，生成物无漂移。

**升级注意**

- 无 schema、参数、错误码或文件行为变更；直接替换二进制即可。
- 未做真实模型对照，不声称效率提升。
