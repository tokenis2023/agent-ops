# fsops v0.2.4

面向 AI Agent 的 Windows 文件操作层，MCP + CLI 双形态。本版加了一个直接减少往返的能力，并把「工具注册了却不被使用」的宿主侧真相写清楚。

## 一行安装

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://github.com/tokenis2023/agent-ops/releases/latest/download/install.ps1 | iex"
```

自动完成：下载最新版 → SHA-256 校验 → 安装到 `%LOCALAPPDATA%\fsops` → 加入用户 PATH → 注册检测到的 Claude Code / Hermes / Codex。

卸载：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://github.com/tokenis2023/agent-ops/releases/latest/download/uninstall.ps1 | iex"
```

## 本版重点

### `fs_edit diff=true`：改完即可自查

```text
ok 1 处修改 (+1 -1) @ 3  /d/repo/src/a.rs  hash=643926e2
@@ 3
-let retries = 3
+let retries = 5
```

- 默认关闭，不改变原有紧凑输出。
- 可与 `dry_run` 组合：先看将改成什么，确认后再落盘。
- 多文件批量编辑时按文件分别给片段。
- 单次最多 60 行，超出标注「diff 已截断」。

以前改完结构只能靠 `fs_read` 回读确认，现在一次调用就能看见变更。

### Hermes 接入：注册成功 ≠ 会被使用

文档里补了实测结论：

- `tools.tool_search.defer: []` **不能**让 MCP 工具变 eager（Hermes 把所有 `mcp-*` 当作可延迟）。
- 真强制只有一条路：专用 profile 关掉 `file`/`coding` 工具集，保留 shell。
- 升级 fsops 后需 `/reload-mcp` 或重启宿主，新 schema 才生效。
- 用 `state.db` 里 `mcp__fsops__%` 的调用计数确认是否真被用；`hermes mcp test` 只证明能握手。
