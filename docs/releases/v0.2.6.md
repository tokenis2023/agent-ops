# fsops v0.2.6

面向 AI Agent 的 Windows 文件操作层，MCP + CLI 双形态。本版两个重点：**读文件先看结构，不先读全文**，以及**把 fsops 变成标准 DSH 插件，插件管理里粘贴仓库地址即可安装**。

## 一行安装

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://github.com/tokenis2023/agent-ops/releases/latest/download/install.ps1 | iex"
```

自动完成：下载最新版 → SHA-256 校验 → 安装到 `%LOCALAPPDATA%\fsops` → 加入用户 PATH → 注册检测到的 Claude Code / Hermes / Codex。

卸载：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://github.com/tokenis2023/agent-ops/releases/latest/download/uninstall.ps1 | iex"
```

## 本版重点

### 结构摘要：先看地图，再进房间

`fs_read summary=true` 只输出「行号|声明」，不展开函数体。按扩展名识别 Rust / Python / JS / TS / Go / Java / C# / C / C++ / Ruby / Shell，并跳过 Rust 的 `mod tests`。

```text
/repo/src/tools.rs utf-8 LF 188.8K 4762行 hash=... 结构摘要（仅声明行，未展开函数体）
16|pub fn tool_defs() -> Vec<Value> {
183|fn read_document(
…
… 104 个符号（共 4762 行）| 用 fs_read block=true start=<行号> 读实现
```

实测 8 个源文件 413 KB → 16 KB（省 96.0%）。摘要不比全文更省时（极短的声明型文件）会明确说明并按全文返回。

### DSH 插件：粘贴仓库地址即可安装

仓库根现在是标准 DSH bundle（`package.json` + `cordis.patch.yml` + `dsh/`）。在 DeepSeek Harness 的「插件 → 添加插件 → 安装第三方插件」里粘贴：

```text
https://github.com/tokenis2023/agent-ops
```

二进制优先复用已安装的 fsops，缺失时按版本从 GitHub Release 下载并校验 SHA-256，缓存到 `%LOCALAPPDATA%\fsops-dsh\<版本>`。

### 其他

- `fsops call <tool> -` 支持从标准输入读 JSON，绕开 Windows 约 32 KB 的命令行上限。
- `fs_write` / `fs_edit` 的大参数可经 stdin 传递，DSH 插件走这条路径。
- `E_NO_MATCH` 补充并发修改的下一步提示。
- 开发：新增 `scripts/check.ps1` 分级检查（fast / commit / full），编辑过程中不再每次跑全套。
