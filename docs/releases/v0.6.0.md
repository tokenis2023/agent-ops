# fsops v0.6.0

面向 AI Agent 的 Windows 文件操作层，MCP + CLI 双形态。本版让升级自己完成自己：新增 `fsops upgrade` 自更新，修掉 `program` 相对路径的提示盲区，并把发版流程本身收进仓库门禁。

## 一行安装

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "& ([scriptblock]::Create([Text.Encoding]::UTF8.GetString((New-Object Net.WebClient).DownloadData('https://github.com/tokenis2023/agent-ops/releases/latest/download/install.ps1')).TrimStart([char]0xFEFF)))"
```

卸载：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "& ([scriptblock]::Create([Text.Encoding]::UTF8.GetString((New-Object Net.WebClient).DownloadData('https://github.com/tokenis2023/agent-ops/releases/latest/download/uninstall.ps1')).TrimStart([char]0xFEFF)))"
```

## 本版改动

### 自更新

```powershell
fsops upgrade --check   # 只查有没有新版
fsops upgrade           # 下载 → SHA-256 校验 → 就地替换
fsops upgrade --force   # 已是新版也重装
```

- 跟随 `releases/latest` 重定向取 tag；下载二进制与 `.sha256`，SHA-256 不匹配直接中止，不碰任何文件。
- 替换用「先改名再落新版」：Windows 允许重命名正在运行的自身，失败自动回滚；旧文件保留为 `fsops.exe.old-<时间戳>`，下次升级自动清理。
- 网络瞬时失败重试 3 次（HTTP 4xx 不重试）；错误文案直接给下一步。
- 只升级当前命令对应的二进制；升级后 MCP 宿主执行 `/reload-mcp` 或重启，Hermes 执行 `hermes gateway restart`。

### 修复与指引

- `fs_exec` 的 `program` 用相对路径或 `/d/...` 形式且启动失败时，错误直接说明「相对路径不随 cwd 解析」，并给出原生绝对路径示例。
- 系统引导、AGENTS 规则与使用指南补充：前台 `fs_exec` 控制在 2 分钟内，更长的构建/测试用 `background=true` 拿 job id，再用 `job wait_ms=60000` 轮询——宿主对单次工具调用有更短超时，前台硬等会丢结果。

### 发布工具链

- `scripts/release.py` 新增 `check` / `prepare` / `fill`：版本一致性检查（7 个位置）、升版本与文档引用同步、发布正文骨架、SHA-256/大小回填。
- 新增 `tests/release_tooling.py`；CI 与 `check.ps1 full` 增至 9 项门禁（新增版本一致性与发布工具自检）。
