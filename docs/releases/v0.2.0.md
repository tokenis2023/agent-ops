# fsops v0.2.0

Windows 文件操作层，面向所有支持 MCP 的编码 Agent。

## 下载

- `fsops-v0.2.0-windows-x86_64.exe`
- `fsops-v0.2.0-windows-x86_64.exe.sha256`

## 校验

```powershell
Get-FileHash .\fsops-v0.2.0-windows-x86_64.exe -Algorithm SHA256
```

期望值：

```text
a33a8b1b88d9095bf05a5686ff83fae54a9a0d68e9f50bd94e769613571f08d8
```

文件大小：1,856,000 字节。

## 本版重点

- 单文件读完即得文档与 hash，支持多区间读取和完整长行。
- 大于 32 MB 的文本支持连续区间流式读取。
- 搜索改为流式遍历，支持 files/count/matches/snippets、分页、并行和严格预算。
- `fs_edit` 支持多文件批量编辑，全部预检后写入。
- 编辑和写入增加跨进程写锁与锁内 hash 校验。
- `fs_stat` 新增 meta/hash/full，元信息模式不读文件内容。
- GBK 不可表示字符、混合换行、读取失败等路径增加保护性错误。
- 仓库、文档和接入示例不包含开发机路径或环境配置。
