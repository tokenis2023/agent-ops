# fsops v0.2.7

面向 AI Agent 的 Windows 文件操作层，MCP + CLI 双形态。本版把三件事一起做了：**少一轮、少一点、少试错**，并新增 `fs_exec` / `fs_file` 来替代 PowerShell 的日常操作。工具面从 6 个扩到 8 个。

## 一行安装

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://github.com/tokenis2023/agent-ops/releases/latest/download/install.ps1 | iex"
```

自动完成：下载最新版 → SHA-256 校验 → 安装到 `%LOCALAPPDATA%\fsops` → 加入用户 PATH → 注册检测到的 Claude Code / Hermes / Codex。

卸载：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://github.com/tokenis2023/agent-ops/releases/latest/download/uninstall.ps1 | iex"
```

## 本版重点

### 少一轮：一次调用读多个文件的不同区间

```json
{"reads":[{"path":"/d/a.rs","start":10,"end":40},{"path":"/d/b.rs","start":1,"end":20}]}
```

配合 `focus=<正则>` 直接取回命中所在的完整代码块，以及 `fsops mcp --jobs N` 让同一回复里的多个只读调用真正并行（4 个并发读 14ms → 9ms）。

### 少一点：未变更短路 + 自适应预算

同一 MCP 会话内同文件同 hash 同区间再读，只回一行摘要（带 hash/区间/总行数/首行锚点）——实测重复读输出为正文的 **1.1%**。`force=true` 可重读，`FSOPS_MCP_CACHE=0` 可关闭。

### 少试错：repo map

`fs_glob map=true focus=<关键词>` 按「符号被引用程度 + 入口点 + focus」排序输出文件与关键符号，一次调用回答「先改哪些文件」。fsops 仓库 18 个文件输出 4.9 KB。

### 替代 PowerShell

- **`fs_exec`**：`program` + `args` 数组直接 spawn，不经过 shell——没有引号/插值、`2>&1`、`ErrorRecord`、`$LASTEXITCODE` 问题；非零退出不是错误，超时结束整个进程树；输出自动识别 UTF-8 / GBK。
- **`fs_exec` 后台任务**：`background=true` 立即返回 job id，`job=<id>` 轮询增量输出，`kill=true` 结束进程树，适合 dev server / watch。
- **`fs_file`**：copy / move / remove / mkdir / convert / archive / extract；`remove` 必须 `confirm=true`，`extract` 拒绝 zip-slip。

## 升级提示

- 工具面 6 → 8；DSH 插件与 MCP 的 schema 已同步。
- `fs_exec` 用当前用户权限运行任意程序，**不是安全沙箱**；详见 SECURITY.md。
- 后台任务只在长驻 MCP 会话内有效，`fsops call` 一次性进程会返回 `E_NO_JOB`。
