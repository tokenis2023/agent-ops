# fsops v0.11.2

面向 AI Agent 的 Windows 文件操作层，MCP + CLI 双形态。本版修复 `fs_read` 的两处实测问题：多行函数签名只能取到一行，`reads` 的成功统计与预算分配和实际结果矛盾。

## 一行安装

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "& ([scriptblock]::Create([Text.Encoding]::UTF8.GetString((New-Object Net.WebClient).DownloadData('https://github.com/tokenis2023/agent-ops/releases/latest/download/install.ps1')).TrimStart([char]0xFEFF)))"
```

卸载：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "& ([scriptblock]::Create([Text.Encoding]::UTF8.GetString((New-Object Net.WebClient).DownloadData('https://github.com/tokenis2023/agent-ops/releases/latest/download/uninstall.ps1')).TrimStart([char]0xFEFF)))"
```

## 本版改动

- `focus`/`block` 命中多行签名首行时，向后找到主体 `{` 再配平，返回签名、参数列表与函数体；
  命中在函数体内时块起点上移到签名首行。Rust `where` 子句与 Allman 风格一并覆盖，普通语句不会被误扩。
- `fs_grep expand=block` 复用同一套边界，多行签名的命中同样包含参数列表。
- `reads` 项级校验失败（非对象、缺 `path`、未知字段）计入失败数，头部统计与正文不再矛盾。
- `reads` 顶层预算改为按需分配：小文件先读满，剩余按体积给大文件；显式 `budget` 不参与再分配。

**测试**

- 8 条新回归测试；412 单测与 `scripts/check.ps1 full` 全绿（含真实 MCP e2e 与生成物无漂移）。

**升级注意**

- 无 schema 与错误码变更；`focus`/`block` 返回范围变大属修复。直接替换二进制即可。
